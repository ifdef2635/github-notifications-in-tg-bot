## Основные компоненты

### ✅ **Telegram Bot** (`main.py`, `bot_handlers.py`)
- Регистрация пользователей по команде `/start`  
- Рассылка уведомлений о дедлайнах  
- Команды `/start` (подписаться), `/stop` (отписаться), `/setgithub <логин>` (привязать GitHub-логин)  
- Ежедневная автоматическая проверка в **9:00 UTC** (через `APScheduler`)  

### ✅ **GitHub API Integration** (`github_handler.py`)
- Получение списка открытых задач (`get_issues()`)  
- Парсинг дедлайнов из:  
  - Milestone задачи (`issue.milestone.due_on`)  
  - Текста задачи (по шаблону `Дедлайн: YYYY-MM-DD`)  

### ✅ **База данных SQLite** (`database.py`)
- Хранение `chat_id` подписчиков  
- Методы для:  
  - Добавления пользователей  
  - Удаления пользователей  
  - Получения списка подписчиков  

### ✅ **Конфигурация** (`config.py`)
- Загрузка переменных окружения:  
  - `GITHUB_TOKEN`  
  - `REPO_NAME`  
  - `TELEGRAM_TOKEN`  
- Инициализация клиента GitHub  

## Логика уведомлений
Бот проверяет дедлайны и отправляет уведомления:  
- **За 10, 5, 3, 2, 1 день** до дедлайна  
- **При просрочке** (ежедневно, пока задача не закрыта)  

Пример сообщения:  
```text
⏳ Задача "Реализовать API"
Осталось 3 дня до дедлайна
Ссылка: https://github.com/user/repo/issues/1
```

Пример сообщения о просрочке:  
```text
🔴 Задача "Реализовать API"
Просрочена: 2 дня
Ссылка: https://github.com/user/repo/issues/1
```

## Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ifdef2635/github-notifications-in-tg-bot.git
   cd github-notifications-in-tg-bot
   ```

2. **Создайте виртуальное окружение (опционально) и установите зависимости**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. **Настройте файл .env**:
Создайте файл `.env` в корне проекта и добавьте следующие переменные:
```python
GITHUB_TOKEN="github_pat_1234"
TELEGRAM_TOKEN="1234:QWERTY"
REPO_NAME="your_nick/repo_name"
```
4. **Запустите бота**:
```bash
python main.py
```

## Использование
### *Подпишитесь на уведомления*:
Отправьте команду `/start` в Telegram-боте. Это добавит ваш `chat_id` в список подписчиков.

### *Привяжите GitHub-логин*:
Используйте команду `/setgithub <ваш_логин>`, чтобы связать ваш Telegram-аккаунт с GitHub-логином.
Пример: `/setgithub mylogin`.

### *Создайте задачу в GitHub*:
Добавьте задачу с дедлайном в теле (например, `Дедлайн: 2025-04-15`) или в `milestone`.  

### *Назначьте задачу на пользователя (`assignee`), чей логин привязан через *`/setgithub`.

### *Получайте уведомления*:
Бот отправит уведомления за `10`, `5`, `3`, `2`, `1` день до дедлайна или при просрочке.  

Если у задачи есть assignee, уведомление получают те из них, чей логин привязан (если никто не привязан — не получает никто). Если assignee нет — всем подписчикам. Pull request'ы игнорируются.

Команда `/stop` убирает подписку и привязку логина.
